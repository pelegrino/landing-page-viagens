# Landing Page - Pedido de Orçamento de Viagens

Projeto desenvolvido para demonstrar a criação de uma landing page utilizando HTML, CSS, JavaScript e Git.

## Objetivo

Permitir que o usuário solicite um orçamento de viagem através de um formulário simples.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- API ViaCEP

## Estrutura

```
landing-page-viagens
│
├── index.html
├── css
│   └── style.css
├── js
│   └── script.js
└── README.md
```
