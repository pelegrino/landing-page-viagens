# Landing Page - Pedido de Orçamento de Viagens

Projeto desenvolvido como atividade prática utilizando **HTML5**, **CSS3**, **JavaScript** e **Git**, simulando uma landing page para solicitação de orçamento de viagens.

## Objetivo

Desenvolver uma landing page responsiva que permita ao usuário solicitar um orçamento de viagem, consultar informações sobre o destino escolhido e demonstrar a integração com APIs públicas utilizando JavaScript.

## Funcionalidades

* Landing page responsiva.
* Cabeçalho com apresentação da agência.
* Seção "Quem somos".
* Destinos em destaque.
* Formulário de solicitação de orçamento.
* Seleção de viagem nacional ou internacional.
* Lista dinâmica de destinos conforme o tipo de viagem.
* Consulta de informações do destino por meio de API.
* Exibição dinâmica das informações do destino.
* Rolagem suave até o formulário.
* Validação do formulário.
* Mensagem de confirmação após o envio.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6)
* Git
* GitHub
* Fetch API
* APIs públicas para consulta de informações de destinos

## Organização do desenvolvimento

O projeto foi desenvolvido utilizando o fluxo de trabalho com Git e GitHub por meio das branches:

* **main**: versão estável do projeto.
* **develop**: desenvolvimento das funcionalidades.

Cada etapa foi registrada em commits separados, permitindo acompanhar a evolução do projeto.

## Como executar

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador moderno.

Não é necessária nenhuma instalação adicional.
